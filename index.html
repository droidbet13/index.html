// Common mistakes

  • void Student(...) is wrong: constructors have no return type.
  • name = name; does nothing: use this.name = name;
  • this(...) must be the first statement in a constructor.
  • Writing any constructor removes the free default one.
  • Changing only the return type is not overloading.
  • No this inside static methods.
  • Private fields: use getters/setters, not direct access.
  • b = a copies the reference, not the object.
  • Using a null reference throws NullPointerException.
  • Package name must match the folder structure.
  • Javadoc starts with /**, not /*.
  • Range validation uses &&, not ||.
